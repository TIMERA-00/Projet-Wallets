# Packagist dans le projet E-Wallet

## 1. Définition

Packagist est le dépôt officiel des packages PHP utilisés avec Composer.

---

## 2. Rôle dans notre projet

Si nous améliorons le projet :

- gestion des logs
- sécurité
- validation avancée

nous pouvons installer des packages via Packagist.

---

## 3. Exemple

```bash
composer require monolog/monolog
